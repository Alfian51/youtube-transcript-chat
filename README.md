# 🎬 Video Search Timestamp (Video Ctrl+F)

Solusi pencarian transkrip kata kunci pada video YouTube secara *real-time* berbasis detik/menit (*timestamp*). Proyek ini merupakan pengembangan dan inovasi dari kasus proyek lablab.ai.

## 🚀 Fitur Utama
- **Global Search Keyword:** Mencari percakapan spesifik di dalam video tanpa perlu memutar video secara manual.
- **Auto-Seek Player:** Mengkliknya tombol *timestamp* langsung membawa pemutar video YouTube ke detik kejadian kata kunci tersebut diucapkan.
- **Dynamic Multi-Video Layout:** Menampilkan daftar cuplikan kalimat beserta pengelompokan per judul video.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **API Player:** YouTube Iframe Player API
- **Backend Service:** FastAPI / Supabase (PostgreSQL)
